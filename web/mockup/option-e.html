One-time setup, if any
Nothing to install. macOS lets the browser talk to the panel directly.
One Zadig step, once. Windows needs the WinUSB driver for the panel's recovery mode. With the panel in FEL mode (next step), open Zadig, choose Options → List all devices, pick USB Device (1f3a:efe8), select WinUSB and click Replace driver.
Add a udev rule, once, so your user can open the panel without root: 
SUBSYSTEM=="usb", ATTR{idVendor}=="1f3a", ATTR{idProduct}=="efe8", MODE="0660", TAG+="uaccess"
SUBSYSTEM=="usb", ATTR{idVendor}=="1f3a", ATTR{idProduct}=="1010", MODE="0660", TAG+="uaccess"
Save it as /etc/udev/rules.d/50-s1.rules, then run sudo udevadm control --reload.
Nothing to install. Chrome on Android opens the panel directly. Use a USB-C to USB-C data cable, phone to panel.
