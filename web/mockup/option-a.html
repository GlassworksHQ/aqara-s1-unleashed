Nothing to install. macOS lets the browser talk to the panel directly.
One Zadig step, once. Windows needs the WinUSB driver for the panel's recovery mode. When the panel is in FEL mode (next step), open Zadig, choose Options → List all devices, pick USB Device (1f3a:efe8), select WinUSB and click Replace driver.
Add a udev rule, once, so your user can open the panel without root: 
SUBSYSTEM=="usb", ATTR{idVendor}=="1f3a", ATTR{idProduct}=="efe8", MODE="0660", TAG+="uaccess"
SUBSYSTEM=="usb", ATTR{idVendor}=="1f3a", ATTR{idProduct}=="1010", MODE="0660", TAG+="uaccess"
Save it as /etc/udev/rules.d/50-s1.rules, then run sudo udevadm control --reload.

Step 2 · FEL mode

Put the panel in recovery mode

FEL is a USB recovery mode built into the chip. It can't be erased, which is also why the panel is very hard to brick.

  1. Unplug the panel and take off the back cover.
  2. Find the small button on the board. Not the reset button on the case.
  3. Hold it, plug USB-C into this computer, and keep holding for about 10 seconds.
  4. Release. The screen stays black. That's expected.
Your browser will ask you to pick USB Device (1f3a:efe8)
