# Security

Report security problems privately through
[GitHub's private reporting](https://github.com/GlassworksHQ/aqara-s1-unleashed/security/advisories/new),
not as a public issue. You'll get a reply within a week.

In scope: S1 Kiosk, the installers, the root helper and radio bundle, the update check and its
signature checks, and the ESPHome API on the panel.

Only the latest release gets fixes. Panels update from Home Assistant (*Settings → Updates*).
