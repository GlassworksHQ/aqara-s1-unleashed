# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
It applies in issues, pull requests, Discussions and any other place the project runs.

## Reporting

To report behaviour that breaks it, contact the maintainers privately: open a
[private report](https://github.com/GlassworksHQ/glassworks/security/advisories/new) and start the
title with "Code of conduct". You can also use GitHub's **Report content** on the comment, but pick
**Report to repository admins**: the other choice goes to GitHub Support, not to the maintainers.
Don't report it in public. The maintainers look at every report sent to them and keep the
reporter's identity private.

## Enforcement

The maintainers decide what to do, following the Covenant's
[enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines):
a private warning, a temporary ban, or a permanent ban, depending on what happened.
